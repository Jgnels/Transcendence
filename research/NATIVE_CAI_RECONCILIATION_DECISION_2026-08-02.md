## Decision

The former default application path

`v0.2E challenge → v0.2F portfolio → v0.2G project assignment/commitment → v0.2H assignment-derived feasibility → v0.2I transport → project-owned strategic control`

is **superseded as the default application architecture**.

The new default is:

`Native WH3 CAI planner/executor → Transcendence observation → Transcendence evaluation/diagnosis → native DB tuning → narrowly bounded script correction only after measured failure → project-owned strategic control only after native+tuning falsification`

Native CAI is not presumed optimal. It is the default application owner because current evidence establishes that WH3 already owns materially richer task generation, batching, distance-aware priority, force/task pairing, strength evaluation, recruitment, personality and executor machinery than the project had adequately reconciled before v0.2E-I were built.

## Reversal conditions

A project-owned strategic controller may re-enter the application path only when a native failure is:

1. reproducible on preregistered observable metrics;
2. materially relevant to the target player experience;
3. not adequately corrected by native DB tuning or a narrower bounded script;
4. demonstrably improved by the project layer in a controlled ablation;
5. compatible with fairness, privacy, determinism and authority boundaries.

Code already written is never evidence for reversal.
