Native responsibility vs. external strategic portfolio
The following are definitely proven native as of 6.3.4:
Task generation from multiple generator sources.
Task combination/batching by type and target.
Task-to-army allocation (pairing).
Defensive-behavior deprioritization via generator replacement.
The following remain unproven as native capabilities:
Cross-theater portfolio prioritization (weighted scoring of which theater globally deserves resources).
Exclusive army assignment (preventing an allocated army from being immediately reallocated).
Temporal commitment (holding an army to a task for a bounded number of turns).
Multi-faction strategic coordination (bloc-level planning).
Answer: The native pipeline demonstrably owns task generation, combination, and force assignment. It does not demonstrably own the higher-level “portfolio” functions (exclusive assignment, temporal commitment, cross-faction coordination) that Transcendence’s v0.2E–v0.2I chain targets.

D. FINAL NARROW CONCLUSION
NATIVE_CAIs_SURFACE_IS_BROAD_BUT_SUFFICIENCY_UNPROVEN
The native CAI pipeline demonstrably includes task generation, multi-source composition, batching, task-to-army allocation, personality-driven strategy, budgeting, construction guidance, military templates, diplomacy weights, and faction-potential scaling. CA has proven that tuning these parameters achieves specific behavioral corrections in attack/defend balance, recruitment, and anti-player fairness.
