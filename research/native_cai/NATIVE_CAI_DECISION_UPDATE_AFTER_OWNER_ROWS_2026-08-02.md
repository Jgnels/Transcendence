## Remaining falsifiers

A project strategic planner can return only if controlled experiments demonstrate an important behavior requirement that:

- native baseline fails;
- targeted native DB tuning fails;
- a bounded script correction fails or is unavailable; and
- the project planner materially improves the preregistered metric without unacceptable fairness/compatibility regressions.

The first such measurements should target recovery misuse, reserve adequacy, directional churn/intent reversal and critical-front response—not hidden native task IDs.
