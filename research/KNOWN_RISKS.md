# Known Risks

| Risk | Severity | Mitigation |
|---|---:|---|
| WH3 does not expose enough authority to replace ordinary battle AI | Critical | Capability probes; separate control from influence; use data tuning or scripted contexts honestly |
| SFO changes invalidate vanilla assumptions | Critical | SFO-first baseline, local pack audit, SFO-only regression cohort |
| Late-game challenge becomes anti-player bias | High | fairness metrics, rival-power coherence metrics, explicit bias detector |
| Personal-project scope drifts into whole-game rewrite | High | active gate, benchmark-linked features, deletion criteria |
| Synthetic lab optimizes simulator artifacts | Critical | calibration against WH3 observations; uncertainty labels; holdout scenarios |
| Copyrighted game/mod assets enter Git | High | private ignored local input directory, manifest hashes only |
| Save corruption or campaign incompatibility | Critical | shadow mode, backups, migrations, rollback, soak tests |
| Overfitting to Karl Franz | Medium | Karl Franz first, then cross-faction validation before general claims |
| Hardest-difficulty bonuses obscure actual intelligence | High | report AI behavior separately from economy/stat bonuses |
