# WH3 Personal AI & Gameplay Project

A public code repository for a personal, SFO-first project to improve Total War: WARHAMMER III campaign challenge, strategic AI, battle behavior where controllable, empire management, and late-game experience for its owner.

## Repository visibility and safety

This repository is intentionally public because the connected ChatGPT/Codex GitHub integration cannot reliably access the owner's private repositories.

Never commit Creative Assembly assets, SFO or other Workshop pack contents, saves, replays, private logs, personal paths, secrets, or API keys. Keep local-only artifacts beneath `local_inputs/`; that directory is protected by `.gitignore`, but GitHub's website can still upload ignored files if they are selected manually.

## Begin

1. Keep proprietary and personal inputs outside Git.
2. Add the previous source-audit bundle under `research/source_audits/`.
3. Complete `intake/OWNER_INPUT_CHECKLIST.md`.
4. Use `prompts/CONTINUE_PROJECT.md` for future autonomous work.
5. Work only against the active gate in `research/CURRENT_STATE.md`.
